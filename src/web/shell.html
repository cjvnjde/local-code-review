git review

Automatic viewed

A file counts as scrolled past when its last line leaves the top of the pane. Collapsed files are skipped, and marks you set by hand are never undone automatically.

Viewed files

Clears every viewed mark for this diff and expands the files that collapsed with their mark. Notes, hidden files, and folder collapse stay as they are.

Hide files

One glob per line or comma separated. * stops at /, ** crosses it, ? is one character. A pattern without / matches the file name at any depth, a trailing / hides everything below it, and # starts a comment. Files you reveal with the eye icon stay visible.

Removed lines

Reads the diff as the file it is about to be: every run of removed lines becomes one line you click to open, and click again to fold away. Nothing is dropped — a run a note is attached to stays open, and jumping to a bookmark or a note inside a fold opens it. Which runs you opened lasts for this read of the diff, not beyond it.

Review file

No review file yet — your first save opens one.

One review file holds the whole conversation: your notes, the agent's replies, and your follow-ups. Saving again adds to it, and restarting lcr picks the newest one back up. New review leaves the current file on disk as it is and opens a fresh one on your next save.

Keeping only the newest deletes the earlier files as each review is saved. Deleting them takes the conversations and the statuses agents wrote back with them; the notes on this page stay.

Expand context

Arrows on a hunk separator pull in the unchanged lines git left out of the diff: down continues the hunk above, up continues the one below. A gap no larger than this opens in one click, and the last separator keeps reaching towards the end of the file.

Note editor

Off by default: enter adds a line and shift+enter saves the note. cmd/ctrl+enter always saves, and esc always cancels.

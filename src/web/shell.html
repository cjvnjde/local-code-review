Automatic viewed

A file counts as scrolled past when its last line leaves the top of the pane. Collapsed files are skipped, and marks you set by hand are never undone automatically.

Viewed files

Clears every viewed mark for this diff and expands the files that collapsed with their mark. Notes, hidden files, and folder collapse stay as they are.

Hide files

One glob per line or comma separated. * stops at /, ** crosses it, ? is one character. A pattern without / matches the file name at any depth, a trailing / hides everything below it, and # starts a comment. Files you reveal with the eye icon stay visible.

Expand context

Arrows on a hunk separator pull in the unchanged lines git left out of the diff: down continues the hunk above, up continues the one below. A gap no larger than this opens in one click, and the last separator keeps reaching towards the end of the file.

Note editor

Off by default: enter adds a line and shift+enter saves the note. cmd/ctrl+enter always saves, and esc always cancels.
